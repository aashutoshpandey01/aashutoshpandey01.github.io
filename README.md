## GitHub API Integration

The portfolio retrieves public GitHub information dynamically.

It displays:

- Public repository count
- GitHub follower count
- Total repository stars
- Recently updated public repositories

The information is retrieved from:

```text
https://api.github.com/users/aashutoshpandey01

https://api.github.com/users/aashutoshpandey01/repos?per_page=100&sort=updated
```

No API key is required for these public endpoints. GitHub rate limits may temporarily affect data loading.

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/aashutoshpandey01/aashutoshpandey01.github.io.git
```

2. Open the project directory:

```bash
cd aashutoshpandey01.github.io
```

3. Open `index.html` in your browser.

No build tools, package installation, or backend server are required.

## Deployment

This website is hosted using **GitHub Pages**.

To update the live portfolio:

1. Modify `index.html`.
2. Commit and push the changes to the repository.
3. GitHub Pages publishes the updated website.
